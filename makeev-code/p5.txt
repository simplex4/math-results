Consider the following research-level math question.

Let $\pm v_1,\ldots,\pm v_n\in\mathbb R^d$ ($d>5$ is given) be vectors of the $A_d$ root system, where $n=d(d+1)/2$. These are the vectors $\{e_i-e_j:i\ne j\}\subset\{x\in\mathbb R^{d+1}:\sum_{i=0}^d x_i=0\}\cong\mathbb R^d$.
Is it true that for every smooth odd function $f:S^{d-1}\to\mathbb R$, there exist $A\in SO(d)$ and $b\in\mathbb R^d$ such that $f(Av_i)=b\cdot Av_i$ for $1\le i\le n$?

Note that the statement is known to be true if $d\le 3$, and false if $d=4,5$. See https://vibemathed.com/problem/makeev-s-conjecture-on-universal-cover for the examples for $d=4,5$. Although these examples are expected to work for larger $d$, the computation cannot be done in reasonable time and the method cannot settle the problem for all $d$. I expect examples to exist for all $d\ge4$. I prefer a solution for all $d$; if you cannot solve it, solving some $d>5$ is also good.
